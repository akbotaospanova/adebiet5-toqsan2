# Қазақ әдебиеті · 5-сынып · 2-тоқсан

«Тәрбиенің қайнар бұлағы» бөлімі бойынша 14 сабақтан тұратын интерактив сайт.

Автор: **Оспанова Ақбота Ахметжанқызы**, №152 мектеп-гимназияның қазақ тілі мен әдебиеті пәні мұғалімі.

## Құрылымы

- `index.html` – сайттың өзі (барлық сабақтар, ойындар, ҚМЖ, Сөздікқор-бот)
- `books/` – үш баспа оқулығының 2-тоқсан беттері (Арман-ПВ, Атамұра, Мектеп)

`books` папкасы `index.html`-мен бір деңгейде тұруы керек, әйтпесе оқулық беттері ашылмайды.

## GitHub Pages арқылы жариялау

1. Репозиторийге `index.html`, `books/` және осы `README.md` файлын жүктеңіз.
2. **Settings → Pages** бөліміне өтіңіз.
3. **Source** тармағында `Deploy from a branch`, branch – `main`, папка – `/ (root)` таңдап, **Save** басыңыз.
4. 1–2 минуттан кейін сайт `https://<пайдаланушы-аты>.github.io/<репозиторий-аты>/` мекенжайында ашылады.

Оқулық беттері тек білім беру мақсатында пайдаланылады.
